# Frankenstein Annotated

A study companion for *Frankenstein* (1831 edition). It plays the full audiobook and stops at each of 312
notes so you can underline the passage and write the note in your own copy. It also has a searchable
list of every annotation, an 88-question quiz, flashcards, a book overview and a progress page.

**How to use it:** open the site and press Play. Progress saves in your browser automatically.
To continue on another phone or computer, press **Save progress**, send yourself the save link,
and open it on the other device.

This is a static site (HTML, CSS, JavaScript). There is no server, no account and nothing to log in to,
and progress is never uploaded anywhere: the save link carries it, in the part after `#`, which browsers
do not send to the web server.

Audiobook: "Frankenstein - full audiobook with rolling text" on YouTube (video AmUuXtVWZb4).
Text: Project Gutenberg #84.
